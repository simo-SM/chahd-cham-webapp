## Features

- Full menu display with **categories**: Salades, Plats, Tacos, Pizzas, Sandwiches, Desserts, Boissons  
- **Add to cart** functionality with live cart sidebar  
- **WhatsApp order integration**: customers can send order details directly  
- **Mobile responsive** layout with toggleable mobile menu  
- **Notifications** for cart actions  
- Product badges for popular or vegetarian items  
- Clean and modern UI design with Tailwind CSS
